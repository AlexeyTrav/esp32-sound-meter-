# OPERA → анкета гостям (простой вариант, Python)

Два скрипта, запускаются вручную, когда у вас открыт OPERA Cloud:

1. **`extract_emails.py`** читает экран *Export Details* в вашем окне Chrome
   и сохраняет гостей в `output/guest_emails_....csv`.
2. **`send_survey.py`** рассылает анкету гостям из этого CSV.

Скрипты не логинятся в OPERA и не ходят по меню. Весь вход, включая MFA,
делаете вы сами.

---

## Установка (один раз)

1. Установите Python 3.10 или новее с python.org. При установке отметьте
   **"Add Python to PATH"**.
2. Откройте эту папку, в адресной строке Проводника наберите `cmd` и нажмите
   Enter. Затем выполните:
   ```
   pip install -r requirements.txt
   copy config.example.ini config.ini
   ```
3. Откройте `config.ini` в Блокноте и заполните его:
   - `[smtp]` — почта, с которой уходят анкеты. Для Office 365:
     `smtp.office365.com`, для Gmail: `smtp.gmail.com`. Для Gmail нужен
     «пароль приложения».
   - `survey_link` — ссылка на вашу анкету (Tally, Google Forms, SurveyMonkey).
   - `[hotel]` — название, адрес и телефон отеля для подписи письма.

   Пароль от почты в файл **не пишется**: скрипт спросит его при отправке.

Текст письма лежит в `templates/survey_email.txt` и `templates/survey_email.html`.
Его можно менять как угодно. В тексте можно использовать подстановки
`{first_name}`, `{last_name}`, `{arrival}`, `{departure}`, `{survey_link}` и `{name}`.

## Каждый раз

1. Запустите **`start_chrome.bat`**. Откроется отдельное окно Chrome.
   **Войдите в OPERA в этом окне** и работайте в нём как обычно.
   Скрипт может читать только это окно, ваш обычный Chrome он не видит.
2. В OPERA откройте: Miscellaneous → Exports → General →
   `MANUAL_RHG_GUEST_STA` → ⋮ → View Exports → нужный файл → **Export Details**.
3. Дважды щёлкните **`run.bat`**. Он:
   - заберёт строки с экрана (сам прокрутит таблицу и нажмёт «Next» на всех
     страницах);
   - покажет, кому и какое письмо уйдёт;
   - спросит `yes/no`, и только после `yes` начнёт отправку.

Шаги можно запускать и по отдельности:

```
python extract_emails.py                 # шаг 1
python send_survey.py                    # шаг 2, только просмотр, ничего не отправляет
python send_survey.py --send             # шаг 2, отправка (спросит подтверждение)
python send_survey.py --test-to me@hotel.com   # одно тестовое письмо себе
python send_survey.py --departed-on 2026-09-25 # только выехавшие в этот день
```

Если `start_chrome.bat` по какой-то причине не подходит, есть запасной путь.
На экране Export Details выделите всё (Ctrl+A), скопируйте (Ctrl+C) и запустите
`python extract_emails.py --clipboard`. Имейте в виду: если таблица длинная и
разбита на страницы, так скопируется только текущая страница.

## Защита от ошибок

- Анкета уходит только гостям, у которых дата выезда уже наступила.
  Проживающим она не отправляется.
- Каждое отправленное письмо записывается в `sent_log.csv`. При повторном
  запуске тот же гость за то же проживание письмо второй раз не получит.
- Если гость просит больше не писать, добавьте его адрес в `unsubscribe.txt`,
  по одному на строку.
- Внутренние логины OPERA (`...@ECHOICE1`) отсеиваются автоматически,
  дубли адресов тоже.

## Канадский закон CASL

Анкета после проживания обычно подпадает под «существующие деловые отношения»
(гость жил у вас в последние 2 года). Но в письме всё равно обязательны три
вещи: название отправителя, почтовый адрес и способ отписаться. Всё это уже
есть в подписи шаблона. Главное, заполните `[hotel]` настоящими данными и
выполняйте просьбы об отписке (для этого есть `unsubscribe.txt`).

## Конфиденциальность

В папке `output/` и в файлах `sent_log.csv` и `unsubscribe.txt` лежат личные
данные гостей. Не пересылайте их и периодически чистите `output/`.
